# PESOfinanzas

Sistema de finanzas de PE$O · **NUMMEROS by CONTAX**

- Enlace oficial: https://nummeros.peso.contaxbolivia.com/
- `index.html`: el sistema (lee y guarda datos en Google Sheets a través de Apps Script).
- `marca/`: logos, íconos, tipografías y colores oficiales de NUMMEROS.
- `mudanza.html`: aviso "Nos mudamos" que ve quien entra por el enlace viejo de Apps Script.
